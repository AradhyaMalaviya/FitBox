# Deployment Guide

FitBox's only canonical production website is [https://fitbox-cto.pages.dev/](https://fitbox-cto.pages.dev/). The production frontend is deployed to the existing Cloudflare Pages project `fitbox`, which serves that hostname.

Use [CLOUDFLARE_PAGES_DEPLOYMENT.md](CLOUDFLARE_PAGES_DEPLOYMENT.md) for build settings, environment variables, SPA routing, and deployment commands. Do not configure another production hostname for this project.
